## Face
# Pinned to A515FXXU8HWI1: this is the only A515F dump we hold, so these are one
# release behind the rest of the blobs. They talk to the HWK1 SEC_FR TA listed
# above, which holds by measurement: the HWI1 and HWK1 SEC_FR (8327525 B) differ
# in exactly 274 bytes -- the 20-byte NT_GNU_BUILD_ID descriptor at [0x1F4,0x207]
# and a 256-byte RSA-2048 signature at [0x7F0D42,0x7F0E41] right behind the
# samsung_drv:samsung_drv identity string. The DER certificate that follows the
# signature is identical (CN=root, notBefore 180802) -- same signing key -- and
# so is the whole TA payload: code, data, dispatch tables and the embedded
# matcher model. No command ABI differs, so none can skew. BIOSUB differs in
# 275 bytes of the same two kinds.
# DISABLE_CHECKELF on the two blobs that extract-files.py points at
# libsecfr_ahandler_compat.so: that library exports three AHandler symbols and
# reaches the rest of libstagefright_foundation.so through its own DT_NEEDED,
# and check_elf_file.py resolves against direct shared_libs only, so it cannot
# follow that hop. The equivalent transitive check, which also asserts that the
# three symbols really bind to the shim, is
# claude/tools/check-face-symbol-closure.py.
